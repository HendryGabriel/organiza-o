# Fluxo de trabalho

- Ao concluir uma alteração solicitada, execute as verificações apropriadas, crie um commit e faça push para `https://github.com/HendryGabriel/organiza-o.git`.
- Essa preferência foi solicitada explicitamente pelo usuário. Não peça confirmação novamente para commits e pushes das alterações autorizadas.
- Não inclua credenciais, chaves de API nem arquivos pessoais de dados nos commits.
- Se o push falhar, preserve o commit local e informe o motivo ao usuário.
